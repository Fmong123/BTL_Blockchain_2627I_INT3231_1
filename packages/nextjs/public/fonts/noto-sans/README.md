# Noto Sans for downloadable PDFs

Unmodified Noto Sans Regular and Bold from the official archived noto-fonts repository:

- https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
- https://github.com/notofonts/noto-fonts/blob/main/LICENSE

Downloaded 25 November 2026. Distributed under the SIL Open Font License 1.1; see OFL.txt. Fonts are served from this application and subset into exported PDFs so Vietnamese text remains selectable and renders without installed system fonts.
